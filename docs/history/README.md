# Historical material

The repository root is the only maintained skill. These files document its
development; their old instructions and completion rules are not active.

- `original/`: exact committed prose skill, README and supporting references.
- `mathematical-discovery-skill.md`: the previous math-focused main skill.
- `previous-references/`: the full pre-consolidation reference set.
- `package-builds.zip`: exact former draft, tuned and discovery package trees
  plus their validation directories. `package-builds.sha256.json` records every
  archived file hash; the migration read back and verified each entry.
- `tooling/`: old package builders and one-time SkillWren repair/application
  scripts. They retain historical paths and are not maintained entrypoints.

The consolidation retains the original broad task scope, the compact SkillWren
ordering contract, conditional evidence/research/game-design guidance, persistent
failures and proof dependencies, and the prohibition on weakened success criteria.
It removes duplicate active editions, repeated reference advice, math-only
default routing and mandatory loading of a conjecture-specific runtime.

Raw historical evidence remains in the repository's `research/` and
`investigations/` directories. Recorded absolute paths describe the original
runs; archived scripts and generated old packages should not be rerun blindly.
Old experimental working copies were moved to ignored `.build/workspaces/`;
they are scratch material, not another distributable edition of the skill.
