checkout, identify unfinished compression concepts and demonstrated defects,
make bounded corrections, and retain reproducible evidence. No paid model calls,
credential-dependent deployment experiment, benchmark relabeling, or publication.

Baseline: SkillWren 0.13.3, commit a5d7d40fab57b90bad0d07bf736479ff23b70808.
Work in `experiments/skillwren/`, an isolated local clone. The original reports
access-related apparent deletions in historical run directories; do not repair or
overwrite those. No AGENTS.md is tracked in the target checkout.

Predeclared questions and decisions:

1. Is there a functioning automatic compressor, or a selector and future design?
   Inspect the implementation map and CLI, measure both entry text and the full
   declared Markdown context of Solve This with the same metric, and exercise
   existing optimized-build controls. If logic expands context, do not call
   translation compression. Exact token counts require a locally available
   tokenizer; label character counts separately. No arbitrary pruning of source
   requirements or claims of semantic preservation from structural checks.
2. Can wrong evidence tags cause incorrect repair pressure, and can a failed
   compile retain enough evidence for diagnosis? Reproduce I7 with the existing
   deterministic probe and scripted adapter. First write failing tests for
   precise evidence-class diagnostics and failure audit retention. Keep the I7
   satisfaction table unchanged: unsupported exec/user/effect obligations must
   still be rejected. Narrow the adapter's evidence-class instructions without
   claiming model improvement from a prompt edit or silently retagging evidence.
3. Can the explainer falsely claim a command-bearing flow changes nothing?
   Reproduce with an exec-only fragment; require the explanation to acknowledge
   possible command effects. Include read-only and no-effect controls. Inspect
   cross-file and complete-form compatibility through the existing tests.

Use the existing offline unit suite as baseline, run focused regressions after
each correction, then run the full suite and generated-plugin drift check.
Preserve failed tests and exact commands in logs. Tool/sandbox failures are
environment observations, not failures in SkillWren's semantics. Never relax a
requirement merely to obtain a green check or smaller output.

Time/cost scope: one offline investigation of these three questions and
reproduction-driven Solve This refinements. Stop each branch when the next
decision is established. A general semantic compressor, deficiency estimator,
